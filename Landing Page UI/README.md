# 🍔 Daily UI #003 – Burger Restaurant Landing Page

A modern and visually engaging **Landing Page UI** created for the **Daily UI Challenge #003**.

This design is for a fictional **Burger Restaurant**, showcasing delicious signature burgers, featured menu items, and a clean call-to-action focused layout. The project emphasizes strong visual hierarchy, attractive food presentation, and an enjoyable browsing experience.

---

## ✨ Challenge

**Daily UI #003 – Landing Page**

> Design a landing page for a product, service, restaurant, or brand. Focus on creating an engaging first impression using compelling headlines, clear call-to-action buttons, and an intuitive layout.

---

## 🎨 Design Concept

The goal was to design an eye-catching landing page for a modern burger restaurant that attracts visitors and encourages them to explore the menu or place an order.

The interface combines:

- Modern and clean layout
- High-quality burger photography
- Warm and appetizing color palette
- Strong call-to-action buttons
- Well-organized content sections
